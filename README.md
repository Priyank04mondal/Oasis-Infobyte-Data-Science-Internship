# Oasis Infobyte Data Science Internship

This repository contains the projects completed as part of my Data Science Internship at Oasis Infobyte.

## Projects

### Task 1: Iris Flower Classification
- Built a machine learning model to classify Iris flower species.
- Used data preprocessing, model training, and evaluation.

### Task 3: Car Price Prediction
- Developed a machine learning model to predict car prices.
- Performed data cleaning, exploratory data analysis, and model evaluation.

### Task 4: Email Spam Detection
- Built an NLP-based model to classify SMS messages as Spam or Ham.
- Used TF-IDF feature extraction, Multinomial Naive Bayes, and Logistic Regression.
- Evaluated models using Accuracy, Precision, Recall, F1 Score, and Confusion Matrix.
